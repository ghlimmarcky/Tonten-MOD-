# Tonten MOD

Tonten is a lightweight building-assistance mod for Minecraft 26.1.2 / NeoForge.

## Environment

- Minecraft 26.1.2
- NeoForge 26.1.2.29-beta
- Java 25
- Mod version 1.1.2

## Concept

Tonten focuses on small survival-friendly building support rather than large automatic construction.

Main features:

- Tonkachi tools for wood, stone, iron, and diamond
- Flat, vertical, stairs, extend, and air-place support modes
- Temporary Utsusemi Block scaffolding
- Solidify Space Block for longer-lived temporary placement
- Block state preservation for direction-sensitive blocks

## Build

```powershell
.\gradlew.bat build
```

The built jar is generated under `build/libs`.
